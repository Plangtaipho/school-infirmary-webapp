# คู่มือติดตั้ง (สำหรับผู้พัฒนา)

ขั้นตอนมี 2 ส่วน: **ส่วน A** ผู้พัฒนาเตรียม Sheet ต้นแบบ (ทำครั้งเดียว ใช้กับโรงเรียนอื่นได้ด้วย) และ **ส่วน B** ติดตั้งในบัญชีครู (นั่งทำด้วยกันหรือวิดีโอคอล ประมาณ 10–15 นาที)

> เว็บแอปจะทำงานในนามบัญชีที่กด Deploy ดังนั้นขั้น "ทำสำเนา" และ "Deploy" ใน **ส่วน B ต้องกดจาก Gmail ของครูเท่านั้น**

---

## ส่วน A: เตรียม Sheet ต้นแบบ (บัญชีผู้พัฒนา)

### วิธีที่ 1: ใช้ clasp (แนะนำ ถ้ามี Node.js)

```bash
npm install -g @google/clasp
clasp login                                   # เปิดเบราว์เซอร์ให้ล็อกอิน Google
# เปิด https://script.google.com/home/usersettings แล้วเปิด "Google Apps Script API"
clasp create --type sheets --title "ระบบบันทึกห้องพยาบาล (ต้นแบบ)" --rootDir src
clasp push                                     # อัปโหลดทุกไฟล์ใน src/
```

คำสั่งของ clasp อาจต่างกันตามเวอร์ชัน ตรวจด้วย `clasp --help` ก่อน

`clasp create` จะสร้าง Google Sheet ใหม่ใน Drive พร้อมสคริปต์ และสร้างไฟล์ `.clasp.json` (ไม่ commit เข้า git)

### วิธีที่ 2: คัดลอกเองผ่านหน้าเว็บ

1. สร้าง Google Sheet ใหม่ ตั้งชื่อ "ระบบบันทึกห้องพยาบาล (ต้นแบบ)"
2. เมนู **ส่วนขยาย → Apps Script**
3. ⚙️ **การตั้งค่าโปรเจกต์** → ติ๊ก "แสดงไฟล์ Manifest 'appsscript.json' ในเครื่องมือแก้ไข" → วางเนื้อหาจาก `src/appsscript.json`
4. สร้างไฟล์ตามตารางนี้ แล้ววางโค้ดจาก `src/` (ชื่อไฟล์ต้องตรง ไม่ต้องพิมพ์นามสกุล)

| ประเภท | ชื่อไฟล์ |
| --- | --- |
| สคริปต์ | `Config`, `Db`, `Code`, `Students`, `Visits`, `Reports` (ลบ `Code.gs` เดิมแล้ววางทับ) |
| HTML | `Index`, `Styles`, `App` |

5. กดบันทึก (Ctrl+S)

### ทดสอบต้นแบบก่อนส่ง

1. ใน Apps Script เลือกฟังก์ชัน `setupSheets` → **เรียกใช้** → อนุญาตสิทธิ์ → กลับไปดู Sheet จะมีชีต `Students`, `Visits`, `VisitMedicines`, `Settings`, `ErrorLog`
2. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป** (ดูรายละเอียดในส่วน B ข้อ 3) แล้วเปิดลิงก์
3. ทดสอบด้วยไฟล์รายชื่อปลอม: นำเข้า → บันทึก → ออกจากห้อง → ประวัติ → รายงาน → พิมพ์
4. **ล้างข้อมูลทดสอบออกทั้งหมด** ก่อนส่ง: ลบแถวข้อมูลในชีต `Students`, `Visits`, `VisitMedicines`, `ErrorLog` (เหลือแถวหัวตาราง) ส่วน `Settings` เก็บไว้
5. ในชีต `Settings` แถว `school_name` ใส่ "โรงเรียน" ไว้ (ครูแก้เป็นชื่อโรงเรียนจริงภายหลัง)

### สร้างลิงก์ "ทำสำเนา"

1. ปุ่ม **แชร์** → การเข้าถึงทั่วไป: "ทุกคนที่มีลิงก์" สิทธิ์ **ผู้มีสิทธิ์อ่าน** (ต้นแบบไม่มีข้อมูลจริง จึงแชร์ได้)
2. คัดลอกลิงก์ แล้วเปลี่ยนท้ายลิงก์จาก `/edit?usp=sharing` เป็น `/copy`
   ตัวอย่าง: `https://docs.google.com/spreadsheets/d/XXXXXXXX/copy`

## ส่วน B: ติดตั้งในบัญชีครู (ทำพร้อมครู)

1. ให้ครูล็อกอิน Gmail ของตัวเอง แล้วเปิดลิงก์ `/copy` → กด **ทำสำเนา**
   ได้ Sheet ใหม่ใน Drive ของครู สคริปต์ติดมาด้วย ตั้งชื่อเช่น "ห้องพยาบาล ปีการศึกษา 2569"
2. ใน Sheet ของครู เมนู **ส่วนขยาย → Apps Script**
3. ปุ่มสีน้ำเงินมุมขวาบน **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่**
   - ⚙️ เลือกประเภท: **เว็บแอป**
   - คำอธิบาย: `v1`
   - เรียกใช้ในฐานะ: **ฉัน (อีเมลครู)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **เฉพาะตัวฉันเอง**
   - กด **ทำให้ใช้งานได้**
4. กด **ให้สิทธิ์เข้าถึง** → เลือกบัญชีครู
   - ถ้าขึ้น "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง → ไปที่ ... (ไม่ปลอดภัย)** → **อนุญาต**
   - อธิบายครูว่าเป็นเรื่องปกติ เพราะเป็นสคริปต์ในบัญชีครูเอง ไม่ได้ส่งข้อมูลออกไปที่ไหน
5. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) เปิดในเบราว์เซอร์มือถือของครู แล้ว:
   - Android (Chrome): ⋮ → **เพิ่มลงในหน้าจอหลัก**
   - iPhone (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
6. แก้ชื่อโรงเรียนในชีต `Settings` แถว `school_name`
7. นำเข้ารายชื่อนักเรียน: เมนู **นักเรียน → นำเข้าจาก Excel**
8. **ตั้งค่าการแชร์ให้ผู้พัฒนา (ทาง A):** ปุ่มแชร์ของ Sheet → เพิ่ม Gmail ผู้พัฒนาเป็น **ผู้แก้ไข** → การเข้าถึงทั่วไปต้องเป็น **ถูกจำกัด**
   (ทำหลังจากโรงเรียนเซ็นหนังสือยินยอม ดู `CONSENT_TEMPLATE.md`)

### ตรวจสอบหลังติดตั้ง

- [ ] เปิดลิงก์เว็บด้วยบัญชีอื่น (เช่นโหมดไม่ระบุตัวตน) ต้อง**เปิดไม่ได้**
- [ ] การแชร์ Sheet เป็น "ถูกจำกัด" (ไม่ใช่ทุกคนที่มีลิงก์)
- [ ] บันทึกทดสอบ 1 รายการ → เห็นในชีต `Visits` → ยกเลิกรายการทดสอบนั้น
- [ ] ครูเปิด 2-Step Verification ใน Gmail (https://myaccount.google.com/security)
