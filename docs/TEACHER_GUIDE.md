# คู่มือการใช้งานสำหรับครูห้องพยาบาล

เปิดระบบจากไอคอนบนหน้าจอมือถือ หรือบุ๊กมาร์กในคอมพิวเตอร์ (ต้องล็อกอิน Gmail ของครูไว้)

## เมื่อนักเรียนมาห้องพยาบาล

1. กด **+ บันทึกนักเรียนที่มาใหม่** (หรือเมนู **บันทึก**)
2. พิมพ์ชื่อหรือเลขประจำตัวนักเรียน 2–3 ตัว แล้วแตะชื่อที่ขึ้นมา
   - ถ้ามี **กรอบสีแดง "แพ้ยา"** หรือ **กรอบสีส้ม "โรคประจำตัว"** ให้อ่านก่อนให้ยา
3. แตะเลือก **อาการ** (เลือกได้หลายข้อ) ถ้าไม่มีในรายการ พิมพ์ในช่อง "อาการอื่น"
4. แตะเลือก **การดูแล** ถ้าเลือก "ให้ยา" จะมีช่องให้ใส่ชื่อยา จำนวน หน่วย
   - ถ้ายาที่เลือกตรงกับที่นักเรียนแพ้ ระบบจะเตือนสีแดงและถามยืนยันอีกครั้ง
5. ถ้านักเรียน**ยังนอนพักอยู่** ไม่ต้องเลือกผลการจัดการ กด **บันทึก** ได้เลย
6. ถ้าจัดการเสร็จแล้ว เลือก **ผลการจัดการ** (กลับเข้าเรียน / ผู้ปกครองรับกลับบ้าน / ส่งต่อ) แล้วกด **บันทึก**

## เมื่อนักเรียนออกจากห้องพยาบาล

1. หน้า **วันนี้** ดูกล่อง "อยู่ในห้องพยาบาลตอนนี้"
2. กด **ออกจากห้อง** ที่ชื่อนักเรียน → เลือกผลการจัดการ → **บันทึกเวลาออก**
3. ถ้าเลือก "ผู้ปกครองรับกลับบ้าน" หรือ "ส่งต่อ" ระบบจะแสดงเบอร์ผู้ปกครอง แตะเพื่อโทรได้

## บันทึกผิด

เมนู **ประวัติ** → แตะรายการ → **แก้ไข** หรือ **ยกเลิกรายการนี้** (รายการที่ยกเลิกจะไม่ถูกนับในรายงาน)

## ทำรายงาน

เมนู **รายงาน** → เลือก **เดือนนี้ / เดือนที่แล้ว / ภาคเรียน** หรือเลือกวันที่เอง → **ดูรายงาน** → **พิมพ์รายงาน**
(ช่วงวันที่ภาคเรียนเป็นค่าประมาณ แก้วันที่เองได้)

## นักเรียนใหม่ / เปิดปีการศึกษาใหม่

เมนู **นักเรียน** → **นำเข้าจาก Excel** → เลือกไฟล์ → ตรวจตัวอย่าง → **นำเข้า**
- นักเรียนเดิมจะถูกอัปเดตชั้น/ห้อง ข้อมูลแพ้ยาเดิมไม่หาย
- ติ๊ก "ซ่อนนักเรียนที่ไม่อยู่ในไฟล์นี้" เมื่อมีนักเรียนจบ/ย้ายออก

แก้ข้อมูลแพ้ยา โรคประจำตัว เบอร์ผู้ปกครอง: แตะชื่อนักเรียนในเมนู **นักเรียน**

## ข้อควรระวัง

- **ห้ามแชร์ไฟล์ Google Sheet แบบ "ทุกคนที่มีลิงก์"** เพราะเป็นข้อมูลสุขภาพนักเรียน
- ห้ามบอกรหัส Gmail กับใคร และควรเปิดการยืนยัน 2 ขั้นตอน
- เพิ่ม/แก้รายการอาการ ยา ได้ในชีต `Settings` (คอลัมน์ `value`)
- สิ้นภาคเรียน แนะนำให้ดาวน์โหลดสำรอง: ไฟล์ → ดาวน์โหลด → Microsoft Excel
- ถ้าขึ้นข้อความผิดพลาด ให้แคปหน้าจอ (มีรหัสเช่น `ERR-...`) ส่งผู้ดูแลระบบ
